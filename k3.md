# Ручной запуск

### 0) настроить .env в папке бота, а так же второго бота 

```
TOKEN='user_bot_token'
COMMISSION_RATE=1.15
ADDITIONAL_FEE=50
MIN_COMISSION=1000
usd=108
eur=111
gbp=148
jpy=0.8
cny=1
KAFKA_TOPIC="parsing_requests"
KAFKA_RESULT_TOPIC="parsing_results"
KAFKA_BOOTSTRAP_SERVER="kafka:9092"
#All KAFKA* variables defaulted for using with k3d cluster
```

```
KAFKA_BROKER=kafka-service:9092
TELEGRAM_TOKEN="admin_bot_token"
DB_HOST=postgres-service
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=postgres
#All KAFKA* and DB* variables defaulted for using with k3d cluster
```
### 1) создать кластер к3

```
k3d cluster create test
```

### 2) запустить кафку при помощи kafka.yaml в k3s/
```
kubectl apply -f kafka.yaml
```

### 3) запустить рядом бота:
```
cd bot/

docker build -t bot .

k3d image import bot -c test

kubectl apply -f bot.yaml -n kafka
```

### 4) по примеру c ботом запустить парсер

```
cd parser/

docker build -t parser .

k3d image import parser -c test

kubectl apply -f parser.yaml -n kafka
```

основной функционал приложения запущен внутри кластера

# Запуск дополнительного функционала

для остальных сервисов (postgres/ db_go/ spam_bot/) так же предусмотрены докерфайлы и деплоймент конфиги для к3

их можно запустить по примеру с основными сервисами, db_go/ и postgres позволят сохранить каждый заказ и каждого пользователя в бд

spam_bot/ должен быть инструментом заказчика для комфортной работы с базой данных, а так же иметь функционал рассылки по всем пользователям бота(done ~30%)
